# proxmox-lab

Infrastructure as code for O'Neil's two Proxmox VE hosts: create, change and destroy VMs from
code, then configure them with Ansible. Modelled on Christian Lempa's boilerplates approach
(Packer template, Terraform clone, Ansible configure), adapted to this lab.

Status: phases 1 to 4 done (lab, Ansible, prod adopted). Start with `docs/home-setup-map.md`
(where everything lives), then `docs/runbook.md` to work with it. `cheat` in any terminal
lists the commands.

## How it works

```
Packer (later)       Terraform (bpg/proxmox)            Ansible
golden template  ->  clone VM, set CPU/RAM/disk/IP  ->  baseline role, Docker, apps
(Ubuntu 24.04)       writes ansible inventory           runs as turbx over SSH
```

1. **Template**: Ubuntu 24.04 cloud image, with qemu-guest-agent baked in, as template VMID 9000
   on each host. Built by `scripts/prep-host.sh`; Packer replaces it later.
2. **Terraform**: every VM is one entry in a map in `envs/<env>/vms.auto.tfvars`.
   `terraform apply` makes Proxmox match the map. Removing an entry destroys that VM (lab only).
3. **Ansible**: Terraform writes `ansible/inventory/<env>.yml`; playbooks configure the guests.

## Repo layout

```
proxmox-lab/
├── Makefile                  # every command: make help (or lab <command> from anywhere)
├── docs/                     # see the table above
├── scripts/
│   ├── prep-host.sh          # API user, token, storage content, template 9000 (per host)
│   ├── status.sh             # make status
│   ├── vm-locate.sh          # VM name -> host and VMID (make backup, make restart)
│   ├── audit-host.sh         # make audit
│   └── windows/              # prdsrv1 settings and fixed-IP scripts
├── terraform/
│   ├── modules/vm/           # lab VM
│   ├── modules/prod-vm/      # the same VM with prevent_destroy, no auto reboot
│   └── envs/lab, envs/prod/  # prod: prdsrv1 and prdsrv2 imported, new VMs from the template
├── ansible/
│   ├── inventory/            # prod.yml, proxmox.yml, lab generated by Terraform
│   ├── roles/                # pve_host, vm_baseline, shell (deploys the dotfiles), docker
│   └── playbooks/
└── ssh/                      # SSH config snippets written by Terraform (git-ignored)
```
