# proxmox-lab

Infrastructure as code for O'Neil's two Proxmox VE hosts: create, change and destroy VMs from
code, then configure them with Ansible. Modelled on Christian Lempa's boilerplates approach
(Packer template, Terraform clone, Ansible configure), adapted to this lab.

Status: **design, awaiting review**. No code yet.

## How it works

```
Packer (later)       Terraform (bpg/proxmox)            Ansible
golden template  ->  clone VM, set CPU/RAM/disk/IP  ->  baseline role, Docker, apps
(Ubuntu 24.04)       writes ansible inventory           runs as turbx over SSH
```

1. **Template**: Ubuntu 24.04 cloud image, with qemu-guest-agent baked in, as template VMID 9000
   on each host. Built by `scripts/prep-host.sh`; Packer replaces it later.
2. **Terraform**: every VM is one entry in a map in `envs/<env>/vms.auto.tfvars`.
   `terraform apply` makes Proxmox match the map. Removing an entry destroys that VM (lab only).
3. **Ansible**: Terraform writes `ansible/inventory/<env>.yml`; playbooks configure the guests.

## Daily use (target)

```bash
make up   ENV=lab               # apply lab/vms.auto.tfvars
make down ENV=lab NAME=test1    # destroy one lab VM
make list                       # show VMs Terraform manages, per env
make configure ENV=lab          # run Ansible baseline against the env
```

`make down` refuses `ENV=prod`.
